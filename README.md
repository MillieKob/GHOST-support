# GHOST-support
Code written to coordinate and run equipment necessary for a GHOST experiment and perform analysis on the acquired data.

GHOST (Generalised Heterodyne Optical Sampling Techniques) is a field-resolved spectroscopy method operating in up to the Petahertz regime encompassing visible and UV parts of the electromagnetic spectrum. It's a family of techniques which use the nonlinear interaction of the test pulse (pulse to be measured) with a sampling pulse (used for heterodyne detection). In this implementation of the GHOST setup we use the second harmonic of the sampling pulse with the sum frequency of the test and sampling as our local oscillator and heterodyne signal respectively. Hence this is an SFG/SHG GHOST.
